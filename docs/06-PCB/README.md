# PCB Design – Pressure Sensor Subsystem

## Project Overview

This project involves designing a custom PCB for a
pressure-sensing subsystem using KiCad.

The PCB includes a pressure sensor, power regulation,
a PIC18F57Q43 microcontroller interface, and UART
communication for transmitting sensor data to the
system's display subsystem.
